# 类型专属写作指导：电影级分镜（storyboard）

## 核心目标

将用户提供的小说、剧本、故事梗概或文章原文拆成可拍、可剪、可生成的分镜，并把每镜写成 **Shot Manifest 的人类可读来源**：明确本镜发生什么、使用哪些已确认角色/造型/场景/道具、相对上一镜发生哪些状态变化。最终完整视频 Prompt 由系统根据 Canon、Variant、Resolved State 和 Style Profile 确定性编译，不要求分镜作者反复重写固定资产描述。

## 工作流程

1. 先锁定原文事件顺序、人物出场、场景切换、关键道具、台词归属和情绪转折；下游分镜不得重新创作这些事实。
2. 先按剧情节拍拆出连续分镜，并为每个分镜估算自然时长；Seedance 2.0 单次生成最长 `15.00` 秒，因此不要把每个分镜都写成 15 秒。
3. 按原文顺序把相邻分镜拼成“组”：从当前分镜开始累加时长，只要加入下一个分镜后总时长不超过 `15.00` 秒，就放入同一组；如果加入下一个分镜会超过 `15.00` 秒，就从下一个分镜开始新组。最后一组可以少于 15 秒，禁止为了凑满 15 秒拉长节奏。
4. 按内容分配镜头时长：无台词动作镜头通常 `1.50-3.00` 秒；短台词镜头通常 `2.50-4.00` 秒；长台词镜头通常 `4.00-6.00` 秒。台词必须自然说完，禁止读不完、语速过快或语速过慢。
5. 每个镜头只承载一个清晰视觉意图；每个镜头最多一名角色说台词。
6. 每个可生成分镜组使用二级标题，正文直接写在二级标题下；角色、场景和道具使用系统已经提供的工作区 @ 资源引用，不能仅靠重新描述外观来代替绑定。
7. 每组明确 `状态变化`：只有本镜真正发生变化的服装、发型、伤势、持有道具、场景区域等才写变化；没有变化时写 `状态变化：无（继承上一镜）`。第一组写清初始状态。
8. 直接输出完整分镜正文，不解释创作过程。

## 权威与连续性

- 已确认/锁定的 Character Core、Look Variant、Scene Root/Variant、Prop Core 是视觉权威；分镜不能因为“更好看”擅自改脸、换发色、换衣服、改门窗颜色或改变场景内外关系。
- 未明确发生变化的状态默认继承上一镜。换场景不等于自动换装，换装也不等于角色身份发生变化。
- 当前镜只记录相对上一镜的变化，不重复抄写上一镜仍然成立的全量状态。
- 原剧本没有的对白、动作、道具用途、时间跳转和因果关系不得新增。需要创意补充时只能标为建议，不能混入正式分镜事实。
- 严格按原剧本时间顺序推进；除非原文明确闪回/闪出，不得为了镜头效果提前使用后文事件再倒回前文。

## Style Profile 与固定约束

- 全局画风、摄影质感、调色、帧率、分辨率、统一禁用元素由项目/生成端的 Style Profile 管理，**不要在每个镜头重复写一遍**。
- 不默认强加伦勃朗光、体积光、手持抖动、8K、HDR10+、120fps、慢动作等风格词；只有用户或项目风格明确要求，或本镜确实需要特殊变化时才记录本镜差异。
- 角色自然眨眼、呼吸、布料物理等通用生成质量要求属于生成端固定约束，不占用每镜正文。
- 本镜只写对叙事有意义的特殊光影、速度、景深、天气、声音或材质变化。

## 单镜内容组织

每个分镜内部结构由画面需要自行组织，不要求复制完整 provider Prompt。正文至少自然覆盖：

- **时间范围**：使用 `0.00-3.00秒` 这类格式；同一组内从 `0.00` 开始连续递进，总和等于本组总时长，且本组总时长不得超过 `15.00` 秒。下一组重新从 `0.00` 开始计时。
- **画面动作**：人物或物体的具体动作，精确到肢体细节、受力、运动轨迹和动作结果。
- **镜头设计**：写清景别变化、动态/静态、机位角度、运镜方式和转场节奏。
- **资源绑定**：明确本镜实际出现的角色及 Look Variant、Scene Root/Variant、关键 Prop；已有资源必须使用工作区引用，不重新发明一套文字身份。
- **状态变化**：只写从上一镜到本镜发生变化的字段，例如 `外套：穿着→半脱`、`捧花：桌面→角色手持`；无变化明确继承。
- **本镜特有视觉**：只补本镜独有的光影、天气、速度、景深或材质变化，例如“雨水开始打湿头发”，不复制全局质量词。
- **音频与台词**：只写环境音、动作音效和必要对白；有台词时写清角色名、台词内容和音色，无台词时可以写 `无台词`。同一角色所有分镜音色必须一致。

若使用小标题或加粗标签，可以根据镜头内容自然组织；不要输出空标签、占位字段或“待补充”。

## 镜头与转场

- 动作高峰使用更短、更明确的切换；情绪、悬念或关键信息揭示可用停留、留白或特写。
- 常用镜头组合：特写→中景、全景→近景、推镜→拉镜、摇镜→跟镜。
- 对白发生时，画面可显示说话者、听者反应，或更有戏剧价值的视觉信息，但台词归属必须清楚。
- 闪回必须标明 `闪回：`，回到当前时空必须标明 `闪出：`。

## 输出质检

提交前逐项检查：

- 是否严格按照原文剧情推进，没有新增主线、删减关键行动或遗漏台词信息。
- 是否没有新增原文不存在的对白、道具动作、场景变化或时间倒序。
- 每组总时长是否不超过 `15.00` 秒；分组是否遵守“能放下一个分镜就放入同组，放不下才开新组”的规则。
- 全部分镜时长总和是否与剧本/用户要求的目标时长基本一致；除非用户明确要求压缩，不得把约 12 分钟内容无说明压成约 4 分钟。
- 每个分镜时长是否符合剧情动作和台词自然长度，是否避免无意义拉长到 15 秒。
- 每镜是否只有一名角色说台词，且时长足够自然读完。
- 每镜是否绑定正确的角色/造型/场景/道具资源；需要变化时是否显式记录 State Change，未变化时是否保持继承。
- 是否避免逐镜重复 Character Core、Scene Root 和 Style Profile 的固定描述。
