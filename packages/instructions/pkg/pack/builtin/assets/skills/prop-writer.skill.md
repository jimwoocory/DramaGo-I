# 类型专属写作指导：道具设定（prop）

## 核心目标

从剧情、剧本、角色和场景上下文中**提取**关键道具，写成可被拍摄、美术、分镜和图像/视频生成复用的稳定 Prop Core；出现明确的损坏、开合、装载、持有状态变化时，再写成 Prop Variant/State。道具文档是事实整理层，不是补写剧情的创作层。

## 风格处理原则

- 不因缺少视觉风格而暂停、追问或要求用户先选择风格；先完成道具文档。
- 若用户本轮明确指定风格，道具描述必须贴合该风格：真人写实强调材质、磨损、尺度和可拍细节；动漫、3DCG、Q 版强调造型轮廓、配色块面和可识别符号。
- 若用户未指定风格，使用风格中性的基础道具描述：轮廓、材质、颜色、尺寸、状态、磨损、标记、光泽和使用关系；不要写死镜头、媒介、渲染方式或画风。
- 图像生成环节可能会自动追加风格预设；本道具文档只需保证道具识别细节和跨镜头连续性。

## 写作重点

- **剧情功能只取原文**：只有原文明确发生或明确说明的用途、线索、持有关系和动作才能写入；不得为了让道具“有戏”新增拍摄、分享、清洁、加热、破坏、传递等原文不存在的行为。
- **可成像细节**：给出轮廓、材质、颜色、尺寸、状态、磨损、标记、光泽等图像模型能解析的视觉信息。
- **使用关系有来源**：谁持有、谁使用、出现在哪些场景、摆放在哪里，只在剧情或已确认设定有依据时写；没有依据时留空或写成可选视觉建议，不得编成事实。
- **Core / State 分层**：每个道具只使用一个二级标题 `## 道具名` 作为 Prop Core；损坏前后、打开/关闭、装满/空置等明确状态变化使用三级标题 `### 状态变体：...`，只写相对 Core 的变化。
- **连续性标记**：列出跨镜头不可改变的独特细节，避免生成时颜色、材质、大小或标识漂移。
- **安全边界**：涉及武器、药品、危险装置等高风险道具时，只描述叙事和视觉设定，不提供现实制作、伤害或规避监管细节。

## 避免事项

- 不新增原文没有的道具、功能、使用者、操作动作、因果结果或传播行为。
- 不因为“画面更丰富”就给道具增加屏幕内容、品牌文字、贴纸、污损或机械结构；未确认内容只能作为可选建议。
- 不把同一道具的临时状态拆成多个彼此无关的二级道具。
