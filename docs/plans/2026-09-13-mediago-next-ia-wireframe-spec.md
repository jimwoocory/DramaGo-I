# MediaGo 下一版信息架构与页面框架线框图规格

日期：2026-09-13
性质：产品 IA / 低保真线框图规格
边界：不修改业务代码，不 commit，不 push。本规格仅用于下一轮视觉/交互验证。

## 1. 负责人裁决

采用“三层 IA”，吸收参考 UI 的创作者气质和创作流程表达，但不复制其双重导航和常驻 27% AI 聊天布局。

- 全局层：跨项目地点。
- 项目工作流层：当前作品要完成什么。
- 上下文助手层：针对当前对象如何与 AI 协作。

Prompt Director 不设一级导航：Asset Director 进入美术设定；Shot Director 进入镜头计划；生成页只展示编译结果、引用、冲突和缺失，不另造一套 Prompt 编辑真相源。

最新战略边界：MediaGo 保留生产控制面、项目真相源和多 Provider 宿主；Pippit/小云雀的 Short Drama、NestAgent、Canvas Runtime 和通用生成执行能力优先复用，不在新 UI 中复制为新的 MediaGo 一级模块。

## 2. 1440×900 桌面框架

### 2.1 AI 助手收起

- 全局左栏：72 px。
- 项目工作流栏：236 px。
- 主工作区：1132 px。
- 顶部项目上下文栏：56 px，高度计入主工作区。

总宽度：72 + 236 + 1132 = 1440。

### 2.2 AI 助手展开

- 全局左栏：72 px。
- 项目工作流栏：236 px。
- 主工作区：752 px。
- 右侧 AI 上下文助手：380 px，可在 360–420 px 之间调整。

总宽度：72 + 236 + 752 + 380 = 1440。

窄屏不保持四栏；AI 助手退化为覆盖式 Drawer。Timeline / Canvas 类宽画布页面默认关闭 AI 助手，并允许项目工作流栏折叠。

## 3. 三层信息架构

### 3.1 全局层：72 px 图标栏

顶部：MediaGo 标识。

主入口：
1. 项目
2. 全局资产库
3. 工具箱 / Studio

底部：
- 帮助
- 设置

禁止在这一层再放“剧本 / 美术设定 / 视频制作 / 素材库”等项目流程入口。

### 3.2 项目工作流层：236 px

顶部：当前项目名称、返回项目列表。

导航：

- 概览
- 创作开发
  - 故事与改编
  - 剧本
  - 美术设定
- 制作
  - 镜头计划
  - 生成任务
  - 分集与时间线
- 项目资源

允许显示轻量状态，例如缺失导演设定、待生成镜头数量、失败任务数量，但不把这里变成 Dashboard。

### 3.3 上下文助手层

AI 不是项目阶段，也不是左侧一级入口。

右上角提供“AI 助手”开关。展开后右侧 380 px 面板根据当前对象切换上下文：

- 故事页：当前故事骨架 / 改编策略。
- 剧本页：当前集 / 当前场。
- 美术设定：当前 Character / Scene / Prop Core 或 Variant。
- 镜头计划：当前 Production Shot + Previous Shot + Continuity。
- Timeline：默认收起，按需唤起。

AI 建议必须明确“将修改什么对象”，结构化修改需要用户确认。

## 4. 顶部项目上下文栏

高度 56 px。

左侧：项目名 + 面包屑，例如：
`贫官之女 / 创作开发 / 美术设定 / 角色`

中间可在确有先后关系的子流程内出现轻量步骤轨道，例如：
`故事骨架 → 改编策略 → 分集大纲 → 剧本初稿`

右侧：搜索、同步/状态、AI 助手开关。

禁止复制项目工作流导航。

## 5. 页面拆分边界

新的项目工作流应拆为独立页面/路由边界，不继续把功能全部塞进 ProjectOverview.tsx。

建议页面边界：

- ProjectOverviewPage
- StoryDevelopmentPage
- ScreenplayPage
- ArtDirectionPage
- ShotPlanningPage
- GenerationTasksPage
- EpisodeTimelinePage
- ProjectResourcesPage

ProjectOverview 只承担项目总览，不继续内嵌大型 Canvas、Timeline、Prompt Director 全功能。

## 6. 核心页面框架

### 6.1 项目概览

顶部：项目名、状态、最近更新时间。

主区域采用 2:1 栅格：
- 左 2/3：当前制作阶段、最近产物、下一步动作。
- 右 1/3：连续性健康度、失败任务、缺失设定、最近活动。

页面不做完整资产管理和完整生成工作台，仅提供“进入阶段”的明确入口。

AI：默认收起；展开时回答项目级进度和下一步，不替代页面导航。

### 6.2 故事与改编

二级 Tab：
- 故事骨架
- 改编策略
- 分集大纲

主区域：编辑化文档工作面，较宽行距和阅读留白；左侧可有轻量章节/节点目录，不另建第三套主导航。

下方/右侧：版本、评论、结构检查。

AI：适合展开，用于当前文档协作。

### 6.3 剧本

二级区域：
- 左侧 190–220 px：集 / 场景目录。
- 中央：剧本编辑器。
- 右侧可选 Inspector：人物、地点、道具引用，不与 AI 面板同时常驻。

AI：右侧可展开，围绕当前集/场/选中文字工作。

### 6.4 美术设定

页头 Tab：
- 角色 Characters
- 场景 Scenes
- 道具 Props

主区域三段：

1. 资产列表 220 px：Core 项目，显示设定完整度、参考图状态、Variant 数量。
2. 视觉工作区：选中资产的主参考图、参考图网格、基础摘要。
3. 设定摘要侧栏 260–300 px：Core / Variant 切换、Must Keep / Avoid、导演设定完整度、Prompt 预览摘要。

关键操作：
- 打开导演卡
- 添加 Variant
- 绑定参考图
- AI 完善

“打开导演卡”再进入 Drawer/Dialog 编辑结构化字段，不能把角色五官、服装、材质、光线等全部平铺在主页面。

Asset Director 属于这里，但不作为左侧一级导航。

### 6.5 镜头计划

页面强调高信息密度。

左侧 190–220 px：Episode → Scene 层级树。

中央主区域：Production Shot 表格/列表，建议列：
- Shot
- 时间
- 主体
- 动作
- 镜头/机位
- Continuity 状态
- 关键帧状态
- 视频状态
- 操作

顶部提供筛选：全部 / 缺资产 / 连续性冲突 / 待关键帧 / 待视频。

每镜操作：
- 镜头详情
- 生成关键帧

“镜头详情”打开 Shot Director Drawer/Dialog，内容包括：
- 镜头理解：Subject / Action / Composition / Camera / Lighting / Mood
- 资产绑定：Character Core/Look、Scene、Props、Previous Shot、State Changes
- Prompt 预览：Image / Video / ComfyUI target
- Continuity / Reference 警告

不把 Shot Director 所有字段直接塞进表格。

### 6.6 生成任务

二级 Tab：
- 正式镜头生成
- 自由生成
- 队列与历史

正式镜头生成：
- 选择 Production Shot
- 显示 ShotManifest / Canon / Previous Shot
- 编译后的 Prompt 只读
- References 只读展示并允许定位来源
- Provider / Model / 参数
- 生成按钮

正式镜头默认关闭自由 Prompt Optimize，避免绕过确定性编译器。

自由生成：保留自由 Prompt 编辑和 Prompt Optimize，用于探索性生成。

### 6.7 分集与时间线

画布优先：
- 顶部 44–48 px：播放 / 导出 / 缩放 / 工作区切换。
- 中央：预览 / Canvas。
- 底部：Timeline，视频、配音、字幕、音乐、素材轨。

AI 默认收起。

项目工作流栏允许折叠到紧凑模式，给时间轴更多横向空间。

## 9. 必须避免的 5 个 UI 误区

1. 左侧全局导航与顶部流程导航重复同一批入口。
2. 把 AI 助手做成永久占 25%–30% 屏幕的固定栏。
3. 把 Prompt Director 作为新的一级导航和新的资产数据库。
4. 为了“创作者感”把镜头、生成、Timeline 也做成大留白杂志版，牺牲信息密度。
5. 把 Pippit 的 Short Drama / NestAgent / Canvas Runtime 原样复制成 MediaGo 一级模块，造成长期双重维护。

## 10. 视觉线框图生成要求

低保真产品线框图，不是高保真成品 UI。

- 画布：16:10 或 3:2 横向设计评审板。
- 风格：灰阶、白底、细灰线、浅灰占位块、极少阴影。
- 仅用少量青绿色表示当前激活导航、主 CTA、状态节点。
- 中文标签清晰、字号足够大，不使用装饰性长文案。
- 设计评审板至少同时展示：
  1. 三层 IA 树；
  2. 1440×900 全局 Shell；
  3. 美术设定页面；
  4. 镜头计划页面；
  5. 小型 callout：生成任务与 Timeline 的布局原则。
- 必须清楚标注 AI 助手“默认收起 / 展开 380px”。
- 必须清楚标注 Prompt Director：Asset Director → 美术设定；Shot Director → 镜头计划；生成页 → 只读编译结果。
- 不出现“小云雀 / NestAgent / Canvas”作为 MediaGo 新一级导航。
